# Variable
ใช้สำหรับจัดเก็บข้อมูล โดยมีชนิดข้อมูลที่สามารถจัดเก็บได้ดังนี้
1. **string** จัดเก็บตัวอักษร
2. **integer** จัดเก็บเลขจำนวนเต็ม
3. **float** จัดเก็บเลขจำนวนเต็มที่มีทศนิยม
4. **boolean** จัดเก็บค่าจริงเท็จ

โดยการตั้งชือตัวแปรจะต้องไม่ซ้ำกัน

## f-string (format-string)
วิธีการเขียนสตริงเพื่อ แทรกค่าตัวแปรหรือ expression เข้าไปในข้อความได้โดยตรง

    name = "Chanokchon"
    age = 25

    text = f"My name is {name} age is {age} year old";
    print(text)
