# Interpreter
เป็นการอธิบายเกี่ยวกับการเรียกใช้งาน python, การส่งอาร์กิวเมนต์, โหมดโต้ตอบ (interactive mode) และการจัดการรหัสอักขระ (Encoding) โดยสามารถสรุปเนื้อหาออกได้ดังนี้

## Invoking the Interpreter (การเรียกใช้งานตัวแปลภาษา)
ตัวแปรภาษา python (interpreter) มักตะถูกติดตั้งไว้ในระบบคอมพิวเตอร์ ซึ่งสามารถเรียกใช้ได้ผ่าน command line โดยบน windows สามารถใช้งานคำสั่ง `py` เพื่อเรียกใช้งานตัวแปรภาษาของ python

#### การออกจากโปรแกรม
- สามารถกดปุ่ม Ctrl + Z เพื่อออกจากโปรแกรม
- สามารถพิมพ์คำสั่ง `quit()` เพื่อออกจากโปรแกรม

#### การแก้ไขบรรทัด
ระบบจะรองรับการเลื่อนลูกศรซ้าย - ขวาเพื่อแก้ไขข้อความ ดูประวัติคำสั่งย้อนหลัง ช่วยเติมคำอัตโนัมติ (Code completion) หากพิมพ์แล้วขึ้นตัวอักษรแปลก ๆ เช่น ^[[D แสดงว่าระบบนั้นไม่รองรับฟิเจอร์ดังกล่าว

#### รูปแบบการทำงานหลัก ๆ
1. **Interactive Mode** หากรันคำสั่งแล้วไม่มีไฟล์ใด ๆ เข้าไป, python จะเข้าสู่โหมดโต้ตอบที่พิมพ์โค้ดแล้วทำงานทันทีทีละบรรทัด
2. **Script Mode** หากเราใส่ชื่อไฟล์ตามหลัง เช่น py main.py มันจะอ่านและประมวลผลโค้ดทั้งหมดในไฟล์นั้น
3. **คำสั่งแบบด่วน (-c)** ใช้คำสั่ง py -c "โค้ดไพธอน" เพื่อสั่งให้ทำงานสั้น ๆ ทันทีในบรรทัดนั้น เช่น py -c "print('Hello World')"
4. **รันโมดูลเหมือนสคริปต์ (-m)** ใช้สำคั่ง py -m ชื่อโมดูล เพื่อรันโค้ดของโมดูลนั้น ๆ
5. **เข้าโหมดโต้ตอบหลังรันสคริปต์เสร็จ (-i)** ใส่ -i ไว้หน้าชื่อไฟล์เพื่อสั่งให้รันไฟล์นั้นจนจบแล้วเปิดโหมดให้เราสั่งงานต่อได้ทันที

### Argument Passing (การส่งอาร์กิวเมนต์/พารามิเตอร์)
เมื่อเราส่งชื่อสคริปต์หรือข้อมูลเพิ่มเติมผ่าน command line ข้อมูลเหล่านั้นจะถูกแปลงเป็น List ของ String และเก็บไว้ในตัวแปรชื่อ argv ซึ่งอยู่ในโมดูลชื่อ `sys` (เรียกใช้งานด้วยคำสั่ง import sys)

ข้อมูลใน `sys.argv[0]` จะเก็บชื่อของแหล่งที่มาเสมอ เช่น
- ถ้าไม่มีการส่งอาร์กิวเมนต์เลย จะเป็นค่าว่าง `('')`
- ถ้ารันผ่านสคริปต์ปกติ จะเก็บชื่อไฟล์นั้น
- ถ้ารันด้วย `-c` จะเก็บค่า `-c`
- ถ้ารันด้วย `-m` เก็บชื่อของโมดูลนั้นไว้

### Interactive Mode (โหมดโต้ตอบ)
เมื่อเข้าสู่โหมดนี้ Python จะแสดงข้อความต้อนรับ เวอร์ชัน และลิขสิทธิ์ จากนั้นจะแสดงเครื่องหมายพร้อมรับคำสั่ง (Prompt)
- **Primary Prompt (>>>)** เครื่องหมายหลัก หมายความว่าระบบพร้อมรับคำสั่งใหม่
- **Secondary Prompt (...)** เครื่องหมายรอง จะปรากฏเมื่อเราพิมพ์คำสั่งที่จำเป็นต้องมีบรรทัดถัดไป (Multi-line) เช่น คำสั่งเงื่อนไข if, วนลูป for หรือการนิยามฟังก์ชัน

    >>> the_world_is_flat = True
    >>> if the_world_is_flat:
    ...     print("Be careful not to fall off!")
    ... 
    Be careful not to fall off!

## The Interpreter and Its Environment (ตัวแปลภาษาและสภาพแวดล้อม)
### Source Code Encoding (รหัสอักขระของซอร์สโค้ด)
- **ค่าเริ่มต้นเป็น UTF-8** โดยปกติแล้วไฟล์สอร์สโค้ดของ Python 3 จะถูกประมวลผลด้วยรหัส UTF-8 เสมอ ทำให้เราสามารถเขียนตัวอักษรภาษาต่างๆ ของโลก (รวมถึงภาษาไทย) ในข้อความ (String literals), ตัวแปร (Identifiers) และคอมเมนต์ได้ แต่อย่างไรก็ตาม แนวทางปฏิบัติที่ดี (Convention) สำหรับไลบรารีมาตรฐานคือควรใช้ภาษาอังกฤษ (ASCII) ในการตั้งชื่อตัวแปรต่างๆ เพื่อให้โค้ดสามารถนำไปใช้ได้ทั่วไป (Portable)
- **การเปลี่ยนระบบ Encoding** หากจำเป็นต้องใช้ Encoding อื่นที่ไม่ใช่ UTF-8 เราต้องประกาศไว้ที่ บรรทัดแรกสุด ของไฟล์ด้วยรูปแบบเฉพาะ เช่น # -*- coding: cp1252 -*-
