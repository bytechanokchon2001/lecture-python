# Data Structure
นี่คือสรุปเนื้อหาและคำแปลอย่างละเอียดของเอกสาร Python Tutorial บทที่ 5: โครงสร้างข้อมูล (Data Structures) ซึ่งเป็นหนึ่งในบทที่สำคัญที่สุดในการทำความเข้าใจการจัดการข้อมูลใน Python

## List
List ในภาษา Python คือ โครงสร้างข้อมูล (Data Structure) ประเภทหนึ่งที่ใช้สำหรับเก็บข้อมูลหลาย ๆ ค่าไว้ในตัวแปรเดียว จัดเป็นระเบียบแบบลำดับ (Sequence) ที่ข้อมูลแต่ละตัวจะมีตำแหน่ง (Index) กำกับไว้ โดยเริ่มต้นจากตำแหน่งที่ 0

โดน list จะมีฟังก์ชันสำคัญต่าง ๆ ให้ใช้จากการข้อมูลใน list ดังนี้
- `.append(value)` เพิ่มข้อมูล value เข้าไปที่ท้ายสุดของ list
- `.extend(iterable)` ยาย list โดยนำข้อมูลทั้งหมดจากโครงสร้างข้อมูลที่วนลูปได้ (เช่น อีก list หนึ่ง) มาต่อท้าย
- `.insert(index, value)` แทรกข้อมูล value ลงในตำแหน่งดัชนี (index) ที่ index ที่กำหนด
- `.remove(value)` ลบข้อมูล x ตัวแรกที่เจอใน list ออก หากไม่พบข้อมูลจะเกิดข้อผิดพลาด *ValueError*
- `.pop(index)` ดึงข้อมูลในตำแหน่งที่ i ออกมาจาก list และส่งคืนค่าค่านั้น (หากไม่ระบุตำแหน่ง จะเป็นการ*ดึงและลบตัวสุดท้าย*)
- `.clear()` ลบข้อมูลทั้งหมดออกจาก list (ทำให้กลายเป็น list ว่าง)
- `.index(value, start_index, end_index)` คืนค่า index แรกที่พบข้อมูล x (สามารถระบุขอบเขตการค้นหาได้)
- `.count(value)` นับจำนวน value ที่ข้อมูลปรากฏใน list
- `.sort(key=non, reverse=false)` เรียงลำดับข้อมูลใน list (จัดการในตัวแปรเดิมเลย ไม่สร้างลิสต์ใหม่)
- `.reverse()` กลับลำดับข้อมูลใน list จากหน้าไปหลัง
- `.copy()` คืนค่าสำเนาแบบตื้น (Shallow Copy) ของ list นั้น ๆ

**ข้อสังเกตจากเอกสาร** Method ที่ทำการแก้ไขข้อมูลในลิสต์โดยตรง (เช่น append, remove, sort) จะไม่มีการส่งคืนค่า (คืนค่าเป็น None เสมอ) ซึ่งเป็นหลักการออกแบบของ Python สำหรับโครงสร้างข้อมูลที่เปลี่ยนค่าได้

## การใช้ list แทน stack
Stack คือโครงสร้างข้อมูลแบบ LIFO (Last-In, First-Out) คือข้อมูลที่เข้าทีหลังสุดจะถูกนำออกมาก่อน เราสามารถประยุกต์ใช้ List ทำเป็น Stack ได้อย่างมีประสิทธิภาพโดยใช้
- `.append()` เพื่อใส่ข้อมูลเข้าไปที่หลังสุด (push)
- `.pop()` เพื่อดึงข้อมูลตัวสุดท้ายออก

## การใช้ list แทน Queue
Queue คือโครงสร้างข้อมูลแบบ FIFO (First-In, First-Out) คือข้อมูลที่เข้ามาก่อนจะถูกนำออกไปก่อน

- **ข้อควรระวัง** แม้ว่าเราจะสามารถใช้ List ทำ Queue ได้ (เช่น ใช้ append เพื่อต่อท้าย และ pop(0) เพื่อดึงตัวแรกออก) แต่ไม่มีประสิทธิภาพ เพราะการลบหรือแทรกข้อมูลที่ตำแหน่งแรกสุดของ List จะทำให้คอมพิวเตอร์ต้องเลื่อนตำแหน่งข้อมูลตัวอื่น ๆ ทั้งหมดขยับไป 1 ช่อง (o(n))
- **แนวทางแก้ไข** เอกสารแนะนำให้ใช้ `collections.deque `ซึ่งถูกออกแบบมาให้เพิ่มและดึงข้อมูลจากทั้งสองฝั่ง (หน้า/หลัง) ได้อย่างรวดเร็ว (o(1)) โดยใช้คำสั่ง `append()` และ `popleft()`

## List Comprehensions (การสร้าง list แบบรวบรัด)
List Comprehension เป็นวิธีที่สั้นและอ่านง่ายในกา*รสร้าง List ใหม่จากลิสต์หรือข้อมูลเดิมที่มีอยู่* โดยมักจะใช้แทนการเขียนลูป for แบบปกติ และช่วยลด Side Effect ของตัวแปรลูปที่อาจหลงเหลืออยู่หลังจบการทำงาน

**แบบธรรมดา**
    squares = []
    for x in range(10):
        squares.append(x**2)

**แบบ list comprehension**
    squares = [x**2 for x in range(10)]

นอกจากนี้ยังสามารถใส่เงื่อนไข if ซ้อนเข้าไปเพื่อกรองข้อมูลได้ เช่น `[x for x in vec if x >= 0]`

## Nested List Comprehensions (การซ้อนทับ)
นิพจน์เริ่มต้นใน List Comprehension สามารถเป็น List Comprehension อีกตัวหนึ่งได้ มักใช้จัดการกับข้อมูลที่เป็นเมทริกซ์ (Matrix) หรือลิสต์สองมิติ เช่น การทำทรานสโพส (Transpose) สลับแถวเป็นคอลัมน์ แต่เอกสารแนะนำว่าในชีวิตจริง ควรใช้ฟังก์ชัน Built-in อย่าง list(zip(*matrix)) จะทำงานได้ดีและเข้าใจง่ายกว่า

## คำสั่ง del (The del statement)
คำสั่ง del ใช้สำหรับลบข้อมูลในลิสต์โดยระบุจาก Index (ต่างจาก pop() ตรงที่ del จะไม่มีการคืนค่าข้อมูลที่ถูกลบออกมา)
- สามารถใช้ลบข้อมูลเป็นช่วง (Slices) ได้ เช่น `del a[2:4]`
- ใช้ล้างข้อมูลทั้งหมดในลิสต์ได้ เช่น `del a[:]`
- ใช้ลบตัวแปรออกจากหน่วยความจำไปเลยก็ได้ เช่น `del a` *(หากเรียกใช้ a อีกหลังจากนี้จะเกิดข้อผิดพลาด)*

## Tuples และ Sequences (ทูเพิลและลำดับข้อมูล)
Tuple เป็นโครงสร้างข้อมูลประเภทลำดับ (Sequence) เช่นเดียวกับ List และ String แต่มีความแตกต่างที่สำคัญคือ *Tuple เป็นสิ่งที่ไม่สามารถเปลี่ยนแปลงค่าได้ (Immutable)* โดยมักจะเก็บข้อมูลที่ประเภทต่างกัน (Heterogeneous) และเขียนโดยใช้เครื่องหมายจุลภาค `,` คั่น (มักครอบด้วยวงเล็บวงกลม ())
- **การสร้าง Tuple ที่มีข้อมูล 1 ตัว** ต้องมีเครื่องหมายจุลภาคปิดท้ายเสมอ ไม่อย่างนั้น Python จะมองเป็นแค่การครอบวงเล็บคณิตศาสตร์ธรรมดา เช่น singleton = 'hello',
- **Tuple Packing & Sequence Unpacking** * การเขียน t = 12345, 54321, 'hello!' เรียกว่า Tuple Packing (การมัดรวม)
- การเขียน x, y, z = t เรียกว่า **Sequence Unpacking**(การกระจายตัวแปรออกมารับค่า) ซึ่งจำนวนตัวแปรฝั่งซ้ายต้องเท่ากับจำนวนข้อมูลใน Tuple ฝั่งขวาพอดี

## Sets (เซต)
Set คือ คอลเลกชันของ**ข้อมูลที่ไม่มีลำดับ** (Unordered) และ**ไม่มีข้อมูลที่ซ้ำกัน** (No Duplicate Elements)
- **ประโยชน์หลัก** ใช้ตรวจสอบการเป็นสมาชิกในเซตอย่างรวดเร็ว (Membership Testing ด้วยคีย์เวิร์ด in) และใช้ตัดข้อมูลที่ซ้ำกันทิ้ง
- **การสร้าง** ใช้เครื่องหมายปีกกา {} หรือฟังก์ชัน set()
  - **ข้อควรระวัง** การสร้างเซตว่าง ต้องใช้ set() เท่านั้น หากเขียน {} จะเป็นการสร้าง Dictionary ว่าง
- **การดำเนินการทางคณิตศาสตร์** รองรับการทำ Union (|), Intersection (&), Difference (-), และ Symmetric Difference (^)
  - **Union (ยูเนียน)** เป็นการนำข้อมูลของทั้งสองเซตมารวมกัน โดยตัวที่ซ้ำกันจะเหลือเพียงตัวเดียว (ตามคุณสมบัติของเซต) โดยใช้เครื่องหมาย `|` หรือ `.union()`
  - **Intersection (อินเตอร์เซกชัน)** เป็นการหาข้อมูลที่มีอยู่ทั้งในเซตแรกและเซตที่สอง (ตัวที่เหมือนกัน) โดยใช้เครื่องหมาย `&` (Ampresand) หรือเมธอด .intersection()
  - **Difference (ผลต่าง)** เป็นการเอาข้อมูลที่อยู่ในเซตตั้งต้น แต่ต้องไม่อยู่ในเซตที่นำมาลบ ใช้เครื้องหมาย `-` (minus) หรือเมธอด `.difference()`
  - **Symmetric Difference (ผลต่างสมมาตร)** เป็นการเอาข้อมูลทั้งหมดของทั้งสองเซต ยกเว้นตัวที่มันซ้ำกัน (หรือพูดง่าย ๆ คือ เอาสมาชิกที่อยู่แค่ในเซตใดเซตหนึ่งเพียงเซตเดียวเท่านั้น) โดยใช้เครื่องหมาย `^` (Caret) หรือเมธอด `.symmetric_difference()`
- รองรับ Set Comprehensions เช่นเดียวกับลิสต์

## Dictionaries (พจนานุกรม)
Dictionary ในภาษาอื่นอาจเรียกว่า "Associative Memories" หรือ "Associative Arrays" เป็นโครงสร้างข้อมูลที่จับคู่ระหว่าง Key : Value โดย ดัชนี (Key) ไม่ได้ใช้ตัวเลขรันตามลำดับเหมือน List แต่จะอ้างอิงผ่าน "Key" ซึ่ง Key *ต้องเป็นประเภทข้อมูลที่เปลี่ยนค่าไม่ได้* (Immutable) เช่น String, Number หรือ Tuple (ที่ไม่มีวัตถุที่เปลี่ยนค่าได้อยู่ข้างใน) ส่วน List ไม่สามารถนำมาเป็น Key ได้

โดยเรามักใช้เก็บข้อมูลที่มีความสัมพันธ์กัน หรือข้อมูลของสิ่งใดสิ่งหนึ่งที่มีคุณลักษณะหลาย ๆ อย่าง

- **การใช้งาน** ดึงค่าผ่าน `d[key]` หรือใช้ `d.get(key)` เพื่อป้องกันการเกิดข้อผิดพลาด KeyError ในกรณีที่ไม่มี Key นั้นอยู่
- คำสั่ง `list(d)` จะพ่นรายการ Key ทั้งหมดออกมาตามลำดับที่ถูกเพิ่มเข้าไป
- คำสั่ง `sorted(d)` จะพ่นรายการ Key ที่เรียงลำดับแล้วออกมา
- **การสร้าง** สามารถใช้ฟังก์ชันโครงสร้าง dict() เพื่อเปลี่ยนลิสต์ของคู่ลำดับ Tuple ให้กลายเป็น Dictionary ได้ เช่น dict([('sape', 4139), ('jack', 4098)])

## สรุป
### List
- ใช้สัญลักษณ์ `[]`
- เปลี่ยนแปลงค่าได้ (Mutable)
- มีข้อมูลซ้ำได้
- **จุดเด่น** เก็บข้อมูลเป็นลำดับเรียงต่อกัน, นำมาทำ Stack ได้ดี
### Tuple
- ใช้สัญญลักษณ์ `()` หรือ `,`
- เปลี่ยนแปรงค่าไม่ได้ (Immutable)
- มีข้อมูลซ้ำกันได้ เก็บข้อมูลคงที่, มักใช้คืนค่าหลายตัวจากฟังก์ชัน
- **จุดเด่น** เก็บข้อมูลเป็นลำดับเรียงต่อกัน, นำมาทำ Stack ได้ดี
### Set
- ใช้สัญลักษณ์ `{}`
- เปลี่ยนแปลงค่าได้ (Mutable)
- ไม่มีข้อมูลซ้ำกันได้
- **จุดเด่น** ค้นหาข้อมูลไวมาก, ลบค่าซ้ำ, ดำเนินการทางคณิตศาสตร์ (เช่น ยูเนียน)
### Dictionary
- ใช้สัญลักษณ์ `{k: v}`
- เปลี่ยนแปลงค่าได้ (Mutable)
- Key ห้ามซ้ำ / Value ซ้ำได้
- **จุดเด่น** เก็บข้อมูลแบบจับคู่ Key-Value เพื่อค้นหาผ่านชื่อ Key
