#  An Informal Introduction to Python
บทนี้เป็นก้าวแรกในการเขียนโค้ดจริง โดยเน้นการใช้ python เป็นเหมือนเครื่องคิดเลขเพื่อทำความเข้าใจกับประเภทข้อมูลพื้นฐาน 3 อย่าง ได้แก่
- ตัวเลข (number)
- ข้อความ (text/string)
- รายการข้อมูล (list)

### พื้นฐานที่ควรรู้ก่อนเริ่ม
- **Comment (คำอธิบายโค้ด)** ใน Python จะเริ่มต้นด้วยเครื่องหมายแฮช # สิ่งที่อยู่หลัง # ไปจนจบแถวจะไม่ถูกนำไปประมวลผล ใช้เพื่อเขียนอธิบายโค้ด
- **สัญลักษณ์พร้อมรับคำสั่ง (>>>)** โค้ดตัวอย่างที่มีเครื่องหมายนี้ แปลว่าเป็นโค้ดที่เราพิมพ์สั่งงานในโหมดโต้ตอบ ส่วนบรรทัดที่ไม่มีเครื่องหมายคือผลลัพธ์ (Output) ที่ระบบตอบกลับมา

## การใช้งาน python เป็นเครื่องคิดเลข
### Number (ตัวเลข)
ใน python จะแบ่งตัวเลขหลัก ๆ ออกเป็น `int` (จำนวนเต็ม เช่น 2, 4, -5) และ `float` (ทศนิยม เช่น 5.0, 1.6) โดยมีตัวดำเนินการทางคณิตศาสตร์ดังนี้
- `+` ใช้สำหรับการบวกเลข
- `-` ใช้สำหรับการลบเลข
- `*` ใช้สำหรับการคูณเลข
- `/` ใช้สำหรับการหารเลข
    - ผลลัพธ์ที่ได้จากการหารจะเป็น `float` เสมอ
- `%` ใช้สำหรับการหารเอาเศษ เช่น 17 % 3 = 2w
- `**` ใช้สำหรับการยกกำลัง เช่น 5 ** 2 = 25
- `=` ใช้สำหรับกำหนดค่าให้กับตัวแปร
- `_` เป็นตัวแปรพิเศษในโหมด interactive โดยค่าผลลัพธ์ล่าสุดที่พิมพ์ออกมาจะถูกเก็บไว้ในตัวแปรชื่อ `_` อัตโนมัติ ทำให้เราสามารถหยิบไปคำนวนต่อได้ง่าย เช่น price + _

### Text (ข้อความ หรือ string)
ข้อความในภาษา Python (ประเภทข้อมูล str) สามารถเขียนครอบด้วยเครื่องหมายอัญประกาศเดี่ยว ('...') หรืออัญประกาศคู่ ("...") ก็ได้ ผลลัพธ์เหมือนกัน
- **การใส่เครื่องหมายคำพูดซ้อนในข้อความ (Escape Character)** ให้ใช้เครื่องหมาย `\` นำหน้า เช่น 'doesn\'t' หรือใช้อัญประกาศคู่แทน เช่น "doesn't"
- **ฟังก์ชัน print()** ช่วยให้แสดงผลข้อความได้สวยงามขึ้น โดยจะตีความอักขระพิเศษ เช่น `\n` ให้เป็นการขึ้นบรรทัดใหม่
- **Raw string (r'...')** หากเราไม่ต้องการให้เครื่องหมาย \ กลายเป็นอักขระพิเศษ (เช่น ในการเขียน Path ไฟล์) ให้เติมตัว r ไว้หน้าข้อความ เช่น print(r'C:\some\name')
- **ข้อความหลายบรรทัด** ใช้เครื่องหมายอัญประกาศ 3 ตัวคู่กัน """...""" หรือ '''...'''
- **การต่อและทำซ้ำข้อความ** ใช้ `+` เพื่อเชื่อมข้อความ และ `*` เพื่อทำซ้ำข้อความ เช่น 3 * 'un' + 'ium' จะได้ 'unununium'
    - ข้อความที่เป็นตัวอักษรดิบวางติดกันจะเชื่อมกันเองอัตโนมัติ (เช่น 'Py' 'thon' กลายเป็น 'Python') แต่ใช้กับตัวแปรไม่ได้
- **indexing (การเข้าถึงตัวอักษรรายตัว)** ใช้เพื่อเข้าถึงตัวอักษรใน string บนตำแหน่งที่ระบุ (เริ่มต้นที่ 0)
    - สามารถใช้ตัวเลขติดลบเพื่อนับจากท้ายข้อความเข้ามาได้ โดยตัวสุดท้ายคือ -1
- **Slicing (การตัดช่วงข้อความ)** จะใช้รูปแบบ `ข้อความ[start:end]` โดยจะดึงตัวอักษรตั้งแต่ตำแหน่ง `start` (นับรวม) ไปจรถึงตำแหน่ง `end` (ไม่นับรวม) เช่น word[0:2]
    - หากละค่าข้างหน้า เช่น [:2] จะหมายถึง เริ่มตั้งแต่ตัวแรกสุด
    - หากละค่าข้างหลัง เช่น [4:] จะหมายถึง ยาวไปจรถึงตัวสุดท้าย
    - ข้อความใน python เปลี่ยนค่าไม่ได้ (immutable) หากพยายามเปลี่ยนค่าบางตำแหน่ง เช่น word[0] = 'J' จะเกิดข้อผิดพลาด TypeError
- **ฟังก์ชัน len()** ใช้ตรวจดูความยาว (จำนวนตัวอักษร) ของข้อความ

### Lists (รายการข้อมูล)
List เป็นประเภทข้อมูลที่ใช้รวบรวมค่าหลายๆ ค่าเข้าด้วยกัน เขียนอยู่ในเครื่องหมายวงเล็บเหลี่ยม [...] และคั่นข้อมูลด้วยจุลภาค , สมาชิกข้างในจะเป็นข้อมูลคนละประเภทกันก็ได้
- **ฟีเจอร์เหมือน** String List สามารถทำ Indexing, Slicing และใช้เครื่องหมาย + เพื่อต่อ List ได้เหมือนกับข้อความ
- **List สามารถเปลี่ยนแปลงค่าได้ (Mutable)** เราสามารถแก้ไขสมาชิกรายตัวใน List ได้โดยตรง เช่น cubes[3] = 64
- **การเพิ่มข้อมูล** ใช้คำสั่ง `.append()` เพื่อต่อสมาชิกใหม่เข้าที่ท้าย List (เช่น cubes.append(216))
- **การกำหนดค่าไม่ได้เป็นการคัดลอก (Assignment passes reference)** ใน Python การสั่ง list2 = list1 *เป็นเพียงการให้ตัวแปรทั้งสองชี้ไปที่ข้อมูลก้อนเดียวกัน* หากแก้ไขข้อมูลผ่านตัวแปรหนึ่ง อีกตัวแปรจะเปลี่ยนตามด้วย (ถ้าต้องการคัดลอกแบบตื้น ให้ใช้ Slicing ช่วย เช่น list_copy = list1[:])
- **การแก้ไขข้อมูลด้วย Slicing** เราสามารถเปลี่ยนค่า ลบค่า หรือล้างข้อมูลใน List เป็นช่วงๆ ได้ด้วยการแทนที่ค่าด้วย Slicing
- **List ซ้อน List (Nested Lists)** เราสามารถสร้าง List ที่เก็บ List ตัวอื่นอยู่ข้างในได้ เช่น x = [[1, 2, 3], [4, 5, 6]] และเข้าถึงด้วย index สองชั้น x[0][1]

## ก้าวแรกสู่การเขียนโปรแกรม
ในหัวข้อนี้บทเรียนได้ยกตัวอย่างการเขียนโค้ดเพื่อหาลำดับ Fibonacci series (ลำดับตัวเลขที่ตัวถัดไปเกิดจากสองตัวหน้าบวกกัน) เพื่อแสดงให้เห็นภาพรวมของโครงสร้างภาษา:

    # ลำดับฟีโบนัชชี
    a, b = 0, 1
    while a < 10:
        print(a)
        a, b = b, a+b

โดยจากโค้ดด้านบน สามารถสรุปได้ดังนี้
- **Multiple Assignment (การกำหนดค่าพร้อมกันหลายตัวแปร)** บรรทัด a, b = 0, 1 จะเป็นการกำหนดค่าให้ a เป็น 0 และ b เป็น 1 พร้อมกัน โดย Python จะคำนวณฝั่งขวาทั้งหมดให้เสร็จก่อน แล้วค่อยส่งค่าไปฝั่งซ้าย
- **while Loop (การวนลูปด้วยเงื่อนไข)** ลูปจะทำงานซ้ำไปเรื่อยๆ ตราบใดที่เงื่อนไข (ในที่นี้คือ a < 10) ยังคงเป็นจริง (True)
    - ใน Python ค่าตัวเลขที่ไม่ใช่ 0, ข้อความที่มีตัวอักษร หรือ List ที่มีสมาชิก จะถูกมองว่าเป็น True ส่วนตัวเลข 0 หรือข้อมูลที่ว่างเปล่า (Empty sequences) จะมองว่าเป็น False
    - ตัวดำเนินการเปรียบเทียบมาตรฐานใช้เหมือนภาษาทั่วไป ได้แก่ 
        - `<` a น้อยกว่า b
        - `>` a มากกว่า b
        - `==` a เท่ากับ b
        - `<=` a น้อยกว่าหรือเท่ากับ b
        - `>=` a มากกว่าหรือเท่ากับ b
        - `!=` a ไม่เท่ากับ b
- **Indentation (การร่นระยะขอบ/ย่อหน้า)** นี่คือเอกลักษณ์สำคัญของ Python! Python จะใช้การย่อหน้า (พิมพ์ Space หรือ Tab) เพื่อจัดกลุ่มของชุดคำสั่ง (Block โค้ด) แทนการใช้ปีกกา {} โค้ดที่อยู่ในลูปเดียวกันจะต้องมีย่อหน้าลึกเท่ากันเสมอ
- **ความสามารถเพิ่มเติมของ print()** เราสามารถใส่ตัวแปรหลายๆ ตัวใน print() โดยคั่นด้วยเครื่องหมายจุลภาค , ระบบจะเว้นวรรคให้เราอัตโนมัติ และเราสามารถใส่ end=',' เพื่อเปลี่ยนไม่ให้มันขึ้นบรรทัดใหม่ แต่ให้จบด้วยเครื่องหมายจุลภาคแทนได้
