# More control flow tool
เครื่องมือควบคุมทิศทางการทำงานของโปรแกรมเพิ่มเติม ถือเป็นบทที่สำคัญมาก ๆ ครับ เพราะเป็นบทที่เริ่มเข้าสู่การควบคุมเงื่อนไข การวนลูป และการสร้างฟังก์ชันเพื่อจัดการโค้ดให้เป็นระบบ

## if statement
เป็นเครื่องมือพื้นฐานที่สุดในการเลือกทำตามเงื่อนไข สามารถใช้ elif (ย่อมาจาก else if) ได้หลายตัว และปิดท้ายด้วย else (หรือไม่เข้าเงื่อนไขใดเลย)

    if x < 0:
        print('ติดลบ')
    elif x == 0:
        print('เป็นศูนย์')
    else:
        print('เป็นบวก')
        
## for statement
ลูป for ใน Python จะแตกต่างจากภาษา C หรือ Java ตรงที่ไม่ได้เป็นการเพิ่มรอบตามตัวเลข (เช่น i++$) แต่เป็นการดึงข้อมูลทีละตัวออกมาจากโครงสร้างข้อมูล (เช่น ข้อมูลใน List หรือตัวอักษรใน String) ตามลำดับ

    animals = ["cat", "dog", "bird"]
    for animal in animals:
        print(animal)

## range() function
เป็นฟังก์ชันที่ใช้สร้างชุดตัวเลข หากต้องการวนลูปตามจำนวนรอบที่แน่นอน เราจะใช้ฟังก์ชัน range() มาช่วยสร้างชุดตัวเลข
- range(5) จะสร้างเลข 0, 1, 2, 3, 4 (เริ่มต้นที่ 0 และไม่รวมเลข 5)
- range(5, 10) จะสร้างเลข 5, 6, 7, 8, 9
- range(0, 10, 3) เพิ่มค่าทีละ 3 จะได้เลข 0, 3, 6, 9
- หากต้องการแปล range() ให้กลายเป็น list ต้องใช้ฟังก์ชัน list() เช่น list(range(3))

## break, continue, else ในการลูป
- break: สั่งให้หยุดการลูปทันที
- continue: สั่งให้ข้ามไปทำลูปรอบถัดไป
- else ในลูป (ฟีเจอร์พิเศษของ python): ชุดคำสั่งใน else จะทำงานก็ต่อเมื่อลูปทำงานจนครบตามปกติ (ในลูป while คือเงื่อนไขกลายเป็นเท็จ หรือลูป for วนครบทุกไอเทม) แต่ถ้าลูปนั้นถูกสั่งให้หยุดกลางคันด้วย break โค้ดในส่วน else จะไม่ทำงาน (มักใช้ในกรณีวนลูปเพื่อค้นหาของ ถ้าหาเจอแล้วสั่ง break แต่ถ้าหาไม่เจอจนจบลูป ให้ทำคำสั่งใน else)

## pass statement
คำสั่ง pass คือคำสั่งที่ "ไม่ทำอะไรเลย" เอาไว้ใช้เป็นโครง (Placeholder) เวลาที่เราต้องสร้างบล็อกโค้ดตามไวยากรณ์ แต่ยังไม่พร้อมจะเขียนโค้ดข้างใน เพื่อไม่ให้โปรแกรมแจ้งเตือนข้อผิดพลาด

## match statement
เป็นการจับคู่รูปแบบ ทำหน้าที่คล้าย switch-case แต่มีความสามารถในการแกะและตรวจสอบโครงสร้างข้อมูล (Structural Pattern Matching) ที่ทรงพลังกว่ามาก

## Defining Function (การสร้างฟังก์ชัน)
เราจะใช้คำสั่ง def ตามด้วยชื่อฟังก์ชันและวงเล็บเพื่อสร้างฟังก์ชัน
- **Docstrings** บรรทัดแรกสุดในฟังก์ชันสามารถใส่ข้อความครอบด้วย """...""" เพื่อเขียนอธิบายหน้าที่ของฟังก์ชันนั้น ๆ ได้
- **ขอบเขตตัวแปร (Scope)** เมื่อมีการเรียกใช้ฟังก์ชัน ตัวแปรภายในฟังก์ชันจะถูกเก็บใน Local symbol table ของตัวเอง ค่าอาร์กิวเมนต์ที่ส่งเข้ามาในฟังก์ชันจะเป็นแบบ call by value (โดยที่ value นั้นคือ object reference ของข้อมูล)
- **การคืนค่า** ฟังก์ชันจะคืนค่าด้วยคำสั่ง return หากไม่มีคำสั่ง return พิมพ์ไว้ Python จะแอบคืนค่าเป็น None กลับไปให้เองโดยอัตโนมัติ

## More on defining function
การส่งค่าให้กับฟังก์ชันมีอยู่ด้วยกัน 3 รูปแบบ
1. **Default argument values** เราสามารถกำหนดค่าเริ่มต้นให้พารามิเตอร์ได้ ทำให้เวลาเรียกใช้ฟังก์ชันจะส่งค่านั้นมาหรือไม่ก็ได้
2. **Keyword Arguments** เราสามารถระบุชื่อพารามิเตอร์ได้โดยตรง ทำให้ไม่ต้องสลับหรือเรียงลำดับตามที่ตั้งไว้ในฟังก์ชันตั้งแต่แรก
3. **Spacial Parameter** เราสามารถบังคับผู้ใช้งานฟังก์ชันได้ว่า ต้องส่งค่าแบบเรียงตามตำแหน่ง (Positional) หรือต้องส่งแบบระบุชื่อตัวแปร (Keyword) โดยใช้สัญลักษณ์ / และ * แบ่งโซน
- ข้อมูลหน้าเครื่องหมาย `/` ต้องส่งแบบเรียงตามตำแหน่งเท่านั้น (ห้ามใส่ชื่อตัวแปร)
- ข้อมูลหลังเครื่องหมาย `*` ต้องส่งแบบระบุชื่อตัวแปรเท่านั้น (ห้ามส่งแบบเรียงตำแหน่ง)

**⚠️ คำเตือนสำคัญจากบทเรียน**ค่าเริ่มต้นจะถูกประมวลผลเพียงครั้งเดียวตอนที่นิยามฟังก์ชัน ดังนั้น หากใช้ข้อมูลประเภทที่เปลี่ยนแปลงค่าได้ (Mutable) เช่น ลิสต์ [] เป็นค่าเริ่มต้น มันจะสะสมค่าจากการเรียกใช้ครั้งก่อน ๆ ! หากไม่ต้องการพฤติกรรมนี้ ให้ใช้ค่าเริ่มต้นเป็น `None` แทน

## Arbitrary Argument List (*args และ kwargs)
- `*agrs` ใช้รับพารามิเตอร์แบบเรียงตำแหน่งได้ไม่จำกัดจำนวน โดยข้อมูลจะถูกมัดรวมกันมาเป็น Tuple (เช่น def concat(*args):)
- `kwargs` ใช้รับพารามิเตอร์แบบระบุชื่อได้ไม่จำกัดจำนวน โดยข้อมูลจะถูกมัดรวมกันมาเป็น Dictionary

## Unpacking Argument Lists (การแกะข้อมูลส่งให้ฟังก์ชัน)
ในทางกลับกัน ถ้าเรามีข้อมูลที่มัดรวมกันอยู่ใน List หรือ Dictionary อยู่แล้ว แต่อยากจะแกะมันออกเพื่อส่งเข้าไปในฟังก์ชันแยกทีละตัวแปร
- ใช้ * เพื่อแกะ List/Tuple (เช่น range(*args))

## lambda expression
ใช้สร้างฟังก์ชันสั้น ๆ ภายในบรรทัดเดียวโดยไม่ต้องใช้ def เขียนในรูปแบบ lambda arguments: expression มักใช้ส่งเป็นอาร์กิวเมนต์ให้ฟังก์ชันอื่นอีกที เช่น การสั่งสลับสิทธิ์การเรียงลำดับข้อมูล (Sorting)
