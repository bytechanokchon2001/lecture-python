# Module
หัวข้อนี้จะอธิบายถึงการแยกโค้ดออกเป็นไฟล์ย่อยๆ เพื่อให้ง่ายต่อการดูแลรักษา และการนำกลับมาใช้ใหม่ (Reusability) ซึ่งใน Python เราจะเรียกว่า Module

## Modules คืออะไร? และการสร้าง Module
แนวคิด: Module คือไฟล์ที่มีนามสกุล `.py` ซึ่งภายในจะบรรจุฟังก์ชัน, ตัวแปร หรือคลาสต่างๆ เอาไว้ เมื่อเราต้องการใช้งานสิ่งเหล่านี้ในไฟล์อื่น เราจะใช้คำสั่ง `import`

#### ตัวอย่างโค้ด
ไฟล์ fibo.py นี่คือ module ของเรา

    def fib1(n):                # เขียนฟังก์ชันหาลำดับฟีโบนัชชีแบบพริ้นต์ออกหน้าจอ
        a, b = 0, 1
        while a < n:
            print(a, end=" ")
            a, b = b, a+b
        print()

    def fib2(n):                # ฟังก์ชันส่งคืนค่าลำดับฟีโบนัชชีเป็นลิสต์
        result = []
        a, b = 0, 1
        while a < n:
            result.append(a)
            a, b = b, a+b
        return result

เมื่อเราต้องการนำไปใช้ในอีกไฟล์หนึ่ง (หรือใน Interactive shell)

    import fibo

    # เรียกใช้งานฟังก์ชันผ่านชื่อโมดูล
    ibo.fib1(1000)

    # เรียกใช้ fib2
    print(fibo.fib2(1000))

## รูปแบบต่างๆ ในการ Import (More on Modules)
Python อนุญาตให้เรานำเข้าโมดูลหรือฟังก์ชันเฉพาะเจาะจงได้หลายรูปแบบ เพื่อความสะดวกในการเขียนโค้ด

#### นำเข้าฟังก์ชันเฉพาะเจาะจงโดยตรง
วิธีนี้ทำให้เรียกใช้ฟังก์ชันได้เลยโดยไม่ต้องพิมพ์ชื่อโมดูลนำหน้า

    from fibo import fib1, fib2

    fib1(1000)
    
    print(fib2(1000))

### นำเข้าทุกอย่าง (from ... import *)
วิธีนี้จะนำเข้าชื่อทั้งหมดที่ไม่ได้ขึ้นต้นด้วย _ (ไม่แนะนำให้ใช้บ่อยเพราะอาจทำให้เกิดความสับสนของชื่อฟังก์ชันที่ซ้ำกัน)

    from fibo import *
    fib(500)

### การตั้งชื่อเล่นหรือนามแฝง (import ... as ...)
ช่วยให้พิมพ์สั้นลง หรือป้องกันชื่อซ้ำ

    import fibo as f
    f.fib1(500)

    from fibo import fib1 as fibonacci
    fibonacci(500)

## การรัน โมดูล เป็นสคริปต์ (__name__ == "__main__")
**แนวคิด** บางครั้งเราต้องการให้โมดูลนั้นสามารถ "กดรันโดยตรง" เพื่อทดสอบโค้ดได้ด้วย แต่เมื่อถูกไฟล์อื่น import ไป โค้ดส่วนทดสอบนั้นจะต้องไม่ทำงาน เราจะใช้คำสั่งตรวจสอบค่าของ `__name__`

#### ตัวอย่าง

    if __name__ == "__main__":
        import sys
        print("Module run from terminal")
        fib1(sys.argv[1])

- โดยหากเรารันคำสั่ง `py fibo.py` โค้ดด้านใน if จะทำงาน
- หากไฟล์อื่น import ไปใช้ โค้ดใน if จะไม่ทำงาน

#### เพิ่มเติมเกี่ยวกับ `__name__` == `"__main__"`
ประโยคนี้คือ **ตัวสลับโหมด** ที่เอาไว้บอก Python ว่า "ถ้าฉันกดรันไฟล์นี้โดยตรง ให้ทำตามโค้ดด้านล่างนี้นะ แต่ถ้าไฟล์อื่นแค่ยืม (import) ฉันไปใช้... ไม่ต้องรันโค้ดส่วนนี้!"

ทุกครั้งที่เราสั่งรันไฟล์ Python ตัวแปลภาษา (Interpreter) จะสร้างตัวแปรพิเศษตัวหนึ่งขึ้นมาแบบอัตโนมัติชื่อว่า `__name__` ให้กับทุกๆ ไฟล์ โดยค่าของตัวแปรนี้จะเปลี่ยนไปตาม **สถานะการใช้งาน** ดังนี้

- **สถานะที่ 1** รันไฟล์นั้นโดยตรง (เป็นไฟล์หลัก/Main)
Python จะตั้งค่าตัวแปร `__name__` ของไฟล์นั้นให้มีค่าเท่ากับสตริง `"__main__"`
- **สถานะที่ 2** ไฟล์นั้นถูก import ไปใช้ในไฟล์อื่น
Python จะตั้งค่าตัวแปร `__name__` ให้กลายเป็น **ชื่อไฟล์** นั้นจริงๆ

## เส้นทางการค้นหาโมดูล (The Module Search Path)
เมื่อเราสั่ง import fibo ระบบของ Python จะเรียงลำดับการค้นหาไฟล์ fibo.py ดังนี้

1. ค้นหาในกลุ่ม Built-in modules (โมดูลที่ติดมากับตัวภาษา)
2. ค้นหาในไดเรกทอรีปัจจุบันที่ไฟล์หลักนั้นรันอยู่
3. ค้นหาในแปรสภาพแวดล้อมที่ชื่อ PYTHONPATH (ถ้ามีการตั้งไว้)
4. ค้นหาในโฟลเดอร์มาตรฐานของระบบปฏิบัติการ (ตอนที่ติดตั้ง Python เช่น โฟลเดอร์ site-packages)

## Standard Modules
Python มาพร้อมกับคลังโมดูลมาตรฐาน (Standard Library) มากมายที่เราเรียกใช้งานได้ทันที ตัวอย่างเช่น โมดูล sys ที่ใช้จัดการระบบและตัวแปรของตัวแปลภาษา (Interpreter)

## ฟังก์ชัน dir()
**แนวคิด** ฟังก์ชัน dir() ใช้สำหรับตรวจสอบว่าภายในโมดูลหนึ่งๆ มีการจำกัดความ (Define) ชื่อฟังก์ชัน คลาส หรือตัวแปรอะไรไว้ให้เราใช้งานบ้าง

    import fibo 

    # ดูชื่อทั้งหมดที่มีอยู่ในโมดูล fibo
    # ผลลัพธ์จะมี ['__name__', 'fib', 'fib2', ...]
    print(dir(fibo))

    # ถ้าเรียก dir() เปล่าๆ จะแสดงชื่อที่มีการประกาศไว้ในหน้าปัจจุบันทั้งหมด
    print(dir())

## Packages
**แนวคิด** ถ้ามีโมดูลหลายๆ ไฟล์ การรวมกลุ่มโมดูลเหล่านั้นไว้ในโครงสร้างแบบโฟลเดอร์ จะเรียกว่า Packages (เปรียบเสมือนโฟลเดอร์เก็บไฟล์ย่อย) การสร้าง Package จะต้องมีไฟล์ชื่อ `__init__.py` อยู่ในโฟลเดอร์นั้นด้วย (แม้จะเป็นไฟล์ว่างๆ ก็ตาม เพื่อบอก Python ว่าโฟลเดอร์นี้คือ Package)

#### โครงสร้างไดเรกทอรี่
- sound                     # Top-level package
  - `__init__.py`           # ทำให้โฟลเดอร์นี้กลายเป็น package ชื่อ sound
  - formats/                # Subpackage ของ sound สำหรับจัดการฟอร์แมตเสียง ชื่อ formats
    - `__init__.py`
    - wav_read.py
    - wav_write.py
  - effects/                # Subpackage ของ sound สำหรับจัดการฟอร์แมตเสียง ชื่อ effects
    - `__init__.py`
    - echo.py

#### ตัวอย่างการ Import มาใช้งานจาก Package:

    # แบบที่ 1 นำเข้าโมดูลแบบเดี่ยว ๆ
    import sound.effects.echo
    sound.effect.echo.filter_effects()

    # แบบที่ 2 นำเข้าเฉพาะโมดูลเพื่อให้เรียกสั้นลง
    from sound.effects import echo
    echo.filter_effects()

    # แบบที่ 3 นำเข้าฟังก์ชันโดยตรงจากโมดูลใน Package
    from sound.effect.echo import filter_effects
    filter_effects()

นอกจากนี้ในหัวข้อยังระบุถึงการอ้างอิงระหว่างโมดูลภายในแพ็กเกจเดียวกัน (Intra-package References) ซึ่งเราสามารถใช้การระบุตำแหน่งแบบสัมพัทธ์ (Relative Import) ได้ เช่น from . import echo (โมดูลในโฟลเดอร์เดียวกัน) หรือ from ..filters import equalizer (ย้อนกลับไปโฟลเดอร์ระดับบน)
